# Portfolio

Personal developer portfolio built with Next.js 14, Tailwind CSS, and GSAP. Designed with a dark aesthetic, custom vector car loader, and interactive components.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Soumyabrataop/portfolio.git

# Install dependencies
npm install

# Run development server
npm run dev -- -p 3001

# Build production bundle
npm run build
```
