# Portfolio

Hey there! This is the source code for my personal corner on the web ([apparely.pro](https://www.apparely.pro)).

I wanted a portfolio that felt fast, dark, and tactile rather than a generic template — something that reflects what I actually spend my time on: building open-source tools, breaking down ML & agentic systems, and solving offensive security / CTF challenges.

## Highlights & Little Details

- **The Aesthetic:** Deep `#0a0a0a` monochrome palette with subtle grain, engineering-style dotted grid lines, and smooth Lenis scrolling.
- **Custom Vector Car Loader:** A hand-animated SVG car loader drifting across the screen on load.
- **Pluckable Footer String:** An interactive GSAP-animated guitar string at the bottom with audio feedback when you strum it.
- **Technical Writings:** Handwritten deep-dives into ML concepts (CMA-ES black-box optimization, Merkle trees in agentic OS) and DSA constraints.
- **CTF Writeups:** Documented solutions and methodology for TryHackMe rooms, Advent of Cyber side quests, and event challenges.
- **Live Activity:** Real-time GitHub contribution activity and filterable project showcases.

## Built With

- **Framework:** Next.js 14 (App Router) & React 18
- **Styling:** Tailwind CSS
- **Animations:** GSAP & `@gsap/react`
- **Smooth Scroll:** Lenis
- **Typography:** Geist Sans & Instrument Serif

## Running Locally

```bash
# Clone the repository
git clone https://github.com/Soumyabrataop/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run development server
npm run dev -- -p 3001

# Build production bundle
npm run build
```
